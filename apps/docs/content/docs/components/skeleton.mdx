## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { Skeleton } from "@ajnacloud/ui";
```

### Granular

```tsx
import { Skeleton } from "@ajnacloud/ui/skeleton";
```

### Basic usage

```tsx
<Skeleton style={{ width: 200, height: 16 }} />
```

Set dimensions to match the content being replaced. Use `style` or your own CSS; generated Tailwind utilities work too when your application uses Tailwind. Skeleton adds the background, rounded corners, and shimmer.

## Accessibility

Skeleton is hidden from assistive technology by default. The shimmer is removed when reduced motion is requested, leaving a static placeholder.

## API reference

Skeleton accepts native `div` props, including `className`, `style`, and an `HTMLDivElement` ref. It defaults to `aria-hidden="true"` and has no required props.

`SkeletonProps` is exported from both `@ajnacloud/ui` and `@ajnacloud/ui/skeleton`.

## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { Badge } from "@ajnacloud/ui";
```

### Granular

```tsx
import { Badge } from "@ajnacloud/ui/badge";
```

### Basic usage

```tsx
<Badge variant="secondary">Draft</Badge>
```

Badge renders a noninteractive `span` by default. Use [Button](/docs/components/button) for an action.

## Accessibility

Use text to convey status rather than color alone. A rendered link needs a descriptive name; decorative icons should not be part of that name.

## API reference

### Badge

| Prop        | Type                             | Default     | Description                                                                                         |
| ----------- | -------------------------------- | ----------- | --------------------------------------------------------------------------------------------------- |
| `variant`   | `BadgeVariant`                   | `"default"` | `default`, `secondary`, `destructive`, `success`, `warning`, `info`, `outline`, `ghost`, or `link`. |
| `render`    | React element or render callback | —           | Replaces the default `span` without an extra wrapper.                                               |
| `className` | `string`                         | —           | Classes merged with the badge's styles.                                                             |
| `ref`       | `Ref<HTMLElement>`               | —           | Ref to the rendered element.                                                                        |

Accepts children, `style`, native span attributes, and ARIA attributes.

### badgeVariants

`badgeVariants({ variant })` returns a class string, defaulting to `"default"`. When using it on a custom element with standalone CSS, include `data-ajna-component="badge"`.

`BadgeProps`, `BadgeVariant`, and `BadgeVariantProps` are exported from both `@ajnacloud/ui` and `@ajnacloud/ui/badge`.

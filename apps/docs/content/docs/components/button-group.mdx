## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { ButtonGroup, Button } from "@ajnacloud/ui";
```

### Granular

```tsx
import { ButtonGroup } from "@ajnacloud/ui/button-group";
import { Button } from "@ajnacloud/ui/button";
```

### Basic usage

```tsx
<ButtonGroup aria-label="History">
  <Button variant="secondary">Undo</Button>
  <Button variant="secondary">Redo</Button>
</ButtonGroup>
```

Keep controls as direct children so their borders and corners join. Use [Toggle Group](/docs/components/toggle-group) when the buttons represent selected values, or [Input Group](/docs/components/input-group) for controls inside a shared input surface.

### Parts

| Part                   | Purpose                                                 |
| ---------------------- | ------------------------------------------------------- |
| `ButtonGroup`          | Joins its children's borders and corners.               |
| `ButtonGroupText`      | Displays a value, prefix, or label beside the controls. |
| `ButtonGroupSeparator` | Adds a decorative divider between filled buttons.       |

## Accessibility

Give each group an `aria-label` or `aria-labelledby`. Each interactive child keeps its own accessible name and focus behavior; grouping does not add arrow-key navigation or selection state.

## API reference

### ButtonGroup

| Prop          | Type                         | Default        | Description                                                                            |
| ------------- | ---------------------------- | -------------- | -------------------------------------------------------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction in which controls join.                                                      |
| `...props`    | Native `div` props           | —              | Includes children, `className`, `style`, ARIA attributes, and an `HTMLDivElement` ref. |

### ButtonGroupText

Accepts native `div` props and a `render` element or callback. Its ref targets the rendered element, a `div` by default.

### ButtonGroupSeparator

Accepts [Separator props](/docs/components/separator#api-reference). Defaults to `orientation="vertical"`, `role="presentation"`, and `aria-hidden="true"`.

### buttonGroupVariants

`buttonGroupVariants({ orientation })` returns the group's class string. The argument is optional and defaults to horizontal. When applying it to a custom element with standalone CSS, include `data-ajna-component="button-group"`.

The parts, helper, and their prop types are exported from both `@ajnacloud/ui` and `@ajnacloud/ui/button-group`.

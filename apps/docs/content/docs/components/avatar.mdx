## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@ajnacloud/ui";
```

### Granular

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@ajnacloud/ui/avatar";
```

### Basic usage

```tsx
<Avatar role="img" aria-label="Alex Morgan">
  <AvatarImage src="/avatars/alex.svg" alt="" />
  <AvatarFallback>AM</AvatarFallback>
</Avatar>
```

Use your own image URL. Set the size on Avatar; its image and fallback fill that space.

### Parts

| Part               | Purpose                                              |
| ------------------ | ---------------------------------------------------- |
| `Avatar`           | Container, size, and image-loading context.          |
| `AvatarImage`      | Image, shown once loaded.                            |
| `AvatarFallback`   | Initials or an icon when the image is unavailable.   |
| `AvatarBadge`      | Status indicator at the bottom inline-end edge.      |
| `AvatarGroup`      | Overlapping row of avatars.                          |
| `AvatarGroupCount` | Additional-member count supplied by the application. |

## Accessibility

For a standalone avatar, give the root `role="img"` and a full accessible name, with `alt=""` on its image. This keeps one name across image and fallback states. Use a real button or link when the avatar performs an action.

## API reference

### Avatar

| Prop        | Type                             | Default  | Description                         |
| ----------- | -------------------------------- | -------- | ----------------------------------- |
| `size`      | `"sm" \| "base" \| "lg"`         | `"base"` | Dimensions and fallback typography. |
| `render`    | React element or render callback | —        | Composes the underlying element.    |
| `className` | String or state callback         | —        | Additional styles.                  |

Accepts Base UI Avatar root props and a ref to its default span.

### AvatarImage

| Prop                    | Type               | Default | Description                                                             |
| ----------------------- | ------------------ | ------- | ----------------------------------------------------------------------- |
| `src`                   | `string`           | —       | Image URL.                                                              |
| `alt`                   | `string`           | —       | Image description; use an empty string when the root supplies the name. |
| `keepMounted`           | `boolean`          | `false` | Loads through a mounted image instead of preloading.                    |
| `onLoadingStatusChange` | `(status) => void` | —       | Receives `idle`, `loading`, `loaded`, or `error`.                       |

Accepts native image props, `render`, a state-based `className`, and an `HTMLImageElement` ref.

### AvatarFallback

Accepts fallback children, an initial `delay` in milliseconds (default `0`), `render`, a state-based `className`, and a ref to its default span.

### Other parts

| Part               | Props                                                           | Ref               |
| ------------------ | --------------------------------------------------------------- | ----------------- |
| `AvatarBadge`      | Native span props and optional icon children.                   | `HTMLSpanElement` |
| `AvatarGroup`      | Native div props.                                               | `HTMLDivElement`  |
| `AvatarGroupCount` | Native span props, count children, and `size` (default `base`). | `HTMLSpanElement` |

All parts accept `style` and `className`. The parts, their prop types, and `AvatarSize` are exported from both `@ajnacloud/ui` and `@ajnacloud/ui/avatar`.

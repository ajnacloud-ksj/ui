## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { DateInput, Field, FieldTitle } from "@ajnacloud/ui";
```

### Granular

```tsx
import { DateInput } from "@ajnacloud/ui/date-input";
import { Field, FieldTitle } from "@ajnacloud/ui/field";
```

### Basic usage

```tsx
<Field>
  <FieldTitle id="appointment-label">Appointment date</FieldTitle>
  <DateInput name="appointment" aria-labelledby="appointment-label" />
</Field>
```

DateInput combines editable date segments with a built-in calendar. Type into the day, month, and year segments, or open the calendar button. Click the calendar's heading to open a scrollable three-column year grid. Use the previous/next arrows to browse months. Set `hideCalendar` when only keyboard entry is needed. The calendar and popup are internal parts of DateInput.

## Examples

### Browse months and choose a year

The calendar heading switches to a three-column year grid. Selecting a year returns to that month; arrows browse months. Browsing does not change the selected date until a day is chosen.

The popup opens from the calendar button by default. Use `isOpen` and `onOpenChange` to control it externally, or `defaultOpen` for an initially open uncontrolled popup. Selection closes the popup by default; `shouldCloseOnSelect={false}` keeps it open.

### Today shortcut

The calendar header includes a Today button between the year switcher and month navigation arrows. It is hidden when the selected date is already today, including while browsing other months or the year view. Otherwise, it selects today's date, preserves any entered time, and closes the popup unless `shouldCloseOnSelect={false}`. When keeping the popup open, it returns to the day grid on today's month, hides Today, and moves focus to the heading. The button is disabled when today is outside the date bounds, unavailable, read-only, or disabled. It never submits the surrounding form.

Today uses the time zone of a zoned value, or a zoned `placeholderValue` when the input is empty. Date-only values use the local time zone. Set `todayLabel` to translate the visible button text; it defaults to Today.

### Hide the calendar

`hideCalendar` removes the calendar button and popup. Segment editing, clearing, locale formatting, validation, and form submission work the same way. It defaults to false.

### Controlled date and clearing

Use `defaultValue` for uncontrolled state, or `value` and `onChange` for controlled state. Values come from `@internationalized/date`; `parseDate` creates a date without a time zone. The clear date button appears only when a date is present. Clearing emits null and restores focus to the first segment. Set `clearable={false}` to hide it. The clear button is disabled for a read-only or disabled value. A native JavaScript Date is not a supported value.

### Bounds and unavailable days

`minValue` and `maxValue` are inclusive and apply to editing and calendar selection. The year grid respects the bounds, and previous/next navigation stops at the first and last available months. `isDateUnavailable` blocks individual dates while keeping them focusable. `placeholderValue` chooses the initial calendar period when the field is empty; it does not select or submit a date.

### Locale and formatting

`locale` controls segment order, separators, placeholders, calendar labels, and the calendar system. Without an override, the inherited React Aria locale applies. The year grid and month navigation follow that calendar system, including its eras and month lengths. For RTL, use an RTL locale and set the surrounding document or section direction. DateInput also supplies the matching Base UI direction to its popup.

The configurable `calendarLabel` (Choose date), `clearLabel` (Clear date), and `todayLabel` (Today) default to English; translate them for your application. `calendarLabel` names the trigger and popup.

### Disabled, read-only, and invalid

`isDisabled` prevents interaction and excludes the value from submission. `isReadOnly` preserves the value and disables the calendar and clear buttons. For server validation, pass `isInvalid`, render FieldError, and connect it through `aria-describedby`. These React Aria state flags use the is-prefix. Connect help text using `aria-describedby` too.

### Forms and reset

`name` submits an ISO date such as 2026-04-12; an empty value submits an empty string. `isRequired`, bounds, and `validate` participate in native validation by default. Use `validationBehavior="aria"` when your application manages validation itself. Native reset restores an uncontrolled defaultValue. Controlled forms should reset their React state too. Calendar and clear buttons do not submit the form.

### Date and time values

A CalendarDateTime adds editable time segments; `granularity` controls precision and `hourCycle` chooses 12/24-hour display. Calendar selection changes the date while preserving the time. ZonedDateTime values are also accepted. Choose time zones explicitly in your application rather than applying the browser's implicit zone to a date-only value.

## Behavior

### Popup placement and styling

DateInput uses Ajna's [Popover](/docs/components/popover), including its standard radius and border, anchored to the full bordered input. Day and year cells use the Ajna base radius, and compact navigation controls use the small radius. It defaults to bottom/start alignment with a 6px gap and collision handling. Customize it with `popoverProps={{ side: "top", align: "end", sideOffset: 8 }}`. `popoverProps.container` changes the portal destination. Do not wrap DateInput in another Popover.

`className` and `style` target the bordered input group; the forwarded ref targets the outer root div. Both props accept React Aria state callbacks. `inputProps.className` customizes the segment container, `segmentClassName` customizes segments, and `popoverProps.className` customizes the popup. `triggerIcon` accepts a decorative React element from any icon library. Both styling modes use the existing Ajna theme tokens.

### Storing dates

CalendarDate represents a day without a time zone. Use `date.toString()` for a date column. Avoid converting a date-only ISO string through native Date when you do not intend UTC conversion. Date/time and zoned values have different serialization semantics; keep the chosen value type consistent throughout the form.

## Accessibility

Give the input an accessible name with FieldTitle and `aria-labelledby`, or a concise `aria-label`. Type into a segment, use Up/Down to edit its value, and Left/Right to move between segments. Tab reaches the clear and calendar buttons. In the calendar, arrow keys move among dates, Page Up/Page Down browse months, and Enter/Space selects a date. The month/year heading is a keyboard-operable button. The year grid supports arrow keys and typeahead; Enter or Space chooses the focused year and returns focus to the heading. Escape dismisses the popup and focus returns to the trigger.

## API reference

| Prop                                                                                      | Purpose                                                                      |
| ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `value`, `defaultValue`, `onChange`                                                       | Controlled or initial date; callback receives a date or null.                |
| `hideCalendar`                                                                            | Hide the built-in calendar button and popup; defaults to false.              |
| `isOpen`, `defaultOpen`, `onOpenChange`                                                   | Control or initialize popup visibility.                                      |
| `shouldCloseOnSelect`                                                                     | Close after choosing a day; defaults to true.                                |
| `clearable`, `clearLabel`                                                                 | Allow clearing populated dates; defaults to true and Clear date.             |
| `calendarLabel`, `triggerIcon`                                                            | Popup/trigger name and decorative icon; label defaults to Choose date.       |
| `todayLabel`                                                                              | Text for the calendar header action; defaults to Today.                      |
| `name`, `isRequired`, `validationBehavior`, `validate`                                    | Native forms and validation.                                                 |
| `minValue`, `maxValue`, `isDateUnavailable`                                               | Shared editing, navigation, and selection limits.                            |
| `isDisabled`, `isReadOnly`, `isInvalid`                                                   | Interaction and validation state.                                            |
| `locale`, `firstDayOfWeek`                                                                | Formatting, calendar system, and week layout.                                |
| `placeholderValue`, `granularity`, `hourCycle`, `hideTimeZone`, `shouldForceLeadingZeros` | Date/time segment display and initial calendar period.                       |
| `className`, `style`                                                                      | Bordered group styling, including state callbacks.                           |
| `inputProps`, `segmentClassName`                                                          | Segment container and segment customization.                                 |
| `popoverProps`                                                                            | Ajna Popover presentation props; anchoring and focus are managed internally. |
| `ref`                                                                                     | Outer root div.                                                              |

Other React Aria DatePicker props are forwarded except `children`; DateInput owns its segments and built-in calendar. Only single-date selection is supported.

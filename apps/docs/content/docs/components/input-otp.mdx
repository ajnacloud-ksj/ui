## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSlot,
  InputOTPSeparator,
  Field,
  FieldLabel,
} from "@ajnacloud/ui";
```

### Granular

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSlot,
  InputOTPSeparator,
} from "@ajnacloud/ui/input-otp";
import { Field, FieldLabel } from "@ajnacloud/ui/field";
```

### Basic usage

Set `length` and render that many slots. Slots follow their DOM order, including across groups. `validationType` defaults to `"numeric"`; the separator is decorative and does not affect the value.

Label the field through the root's `id`, which identifies the first input. Give the remaining slots labels such as `"Character 2 of 6"`.

## Migration from input-otp

| Previous API                | Current API                                           |
| --------------------------- | ----------------------------------------------------- |
| `maxLength`                 | `length`                                              |
| `onChange`                  | `onValueChange`                                       |
| `onComplete`                | `onValueComplete`                                     |
| Slot `index`                | Slots use DOM order                                   |
| Regex exports and `pattern` | `validationType`                                      |
| `pasteTransformer`          | `normalizeValue`, applied to all values               |
| `containerClassName`        | Root `className`                                      |
| Input ref on `InputOTP`     | Input ref on `InputOTPSlot`; root ref points to a div |

The render callback and password-manager options from `input-otp` are removed. Slots are native inputs with their own focus and caret.

### Alphanumeric codes

Use `validationType="alphanumeric"` for letters and numbers. `normalizeValue` can uppercase values; it applies to typed, pasted, controlled, and initial values. Use `validationType="none"` when normalization supplies a custom character rule.

## Accessibility

Provide a visible label for the first slot and individual character labels for subsequent slots. Root `aria-describedby` connects instructions and errors. Keyboard navigation, Backspace, paste, and autofill are managed by Base UI. Keep the native inputs accessible; do not hide them or add extra tab stops to groups and separators.

## API reference

### Public parts

| Export              | Purpose                                                                                            |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| `InputOTP`          | Manages the code and form value. Requires `length`; forwards a div ref.                            |
| `InputOTPGroup`     | Groups slots with joined borders. Accepts div props and a ref.                                     |
| `InputOTPSlot`      | A native character input. Accepts Base UI input props and an input ref.                            |
| `InputOTPSeparator` | A decorative dash between groups. Accepts Base UI separator props, custom children, and a div ref. |

Each part exports a corresponding `…Props` type. Root, slot, and separator accept Base UI's `render` composition and state-based `className` callbacks.

### Root controls

| Prop                                     | Purpose                                                          |
| ---------------------------------------- | ---------------------------------------------------------------- |
| `length`                                 | Number of character slots.                                       |
| `value`, `defaultValue`, `onValueChange` | Controlled or uncontrolled string value.                         |
| `onValueComplete`                        | Called when the code is complete.                                |
| `autoSubmit`                             | Submit the owning form when complete. Defaults to `false`.       |
| `validationType`                         | `"numeric"` (default), `"alpha"`, `"alphanumeric"`, or `"none"`. |
| `normalizeValue`                         | Normalize accepted values before they are committed.             |
| `onValueInvalid`                         | Called when characters are rejected.                             |
| `mask`                                   | Obscure entered characters. Defaults to `false`.                 |
| `id`, `name`, `form`, `required`         | Labeling and form integration.                                   |
| `disabled`, `readOnly`                   | Disable editing or keep the value read-only.                     |
| `autoComplete`                           | Defaults to `"one-time-code"`.                                   |
| `inputMode`                              | Keyboard hint, inferred from the validation type by default.     |

Put `placeholder`, native focus handlers, and input refs on individual slots. Style the field layout through root `className` and the character boxes through slot `className`.

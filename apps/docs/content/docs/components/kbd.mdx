## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { Kbd } from "@ajnacloud/ui";
```

### Granular

```tsx
import { Kbd } from "@ajnacloud/ui/kbd";
```

### Basic usage

```tsx
<Kbd>Esc</Kbd>
```

Kbd displays a hint; your application registers the shortcut.

## API reference

| Part       | Purpose                        | Props               |
| ---------- | ------------------------------ | ------------------- |
| `Kbd`      | A single keycap.               | Native `kbd` props. |
| `KbdGroup` | An inline combination of keys. | Native `kbd` props. |

Both render `kbd` elements, accept children, `className`, `style`, and ARIA attributes, and forward `HTMLElement` refs. They are not interactive controls.

`Kbd`, `KbdGroup`, `KbdProps`, and `KbdGroupProps` are exported from both `@ajnacloud/ui` and `@ajnacloud/ui/kbd`.

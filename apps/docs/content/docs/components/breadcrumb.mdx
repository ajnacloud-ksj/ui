## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbSeparator,
  BreadcrumbPage,
} from "@ajnacloud/ui";
```

### Granular

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbSeparator,
  BreadcrumbPage,
} from "@ajnacloud/ui/breadcrumb";
```

### Basic usage

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/projects">Projects</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Website</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

### Parts

| Part                  | Purpose                                    |
| --------------------- | ------------------------------------------ |
| `Breadcrumb`          | Navigation landmark containing the trail.  |
| `BreadcrumbList`      | Ordered list of locations.                 |
| `BreadcrumbItem`      | One location.                              |
| `BreadcrumbLink`      | Link to a parent location.                 |
| `BreadcrumbPage`      | Current location.                          |
| `BreadcrumbSeparator` | Decorative divider between items.          |
| `BreadcrumbEllipsis`  | Decorative marker for collapsed locations. |

Place separators between items as direct children of BreadcrumbList.

## Accessibility

The navigation landmark defaults to the name “Breadcrumb”; override `aria-label` when needed. BreadcrumbPage sets `aria-current="page"`, and separators and ellipses are hidden from assistive technology.

## API reference

| Part                  | Native props / element | Additional behavior                                |
| --------------------- | ---------------------- | -------------------------------------------------- |
| `Breadcrumb`          | `nav`                  | Defaults to `aria-label="Breadcrumb"`.             |
| `BreadcrumbList`      | `ol`                   | Wrapping row of locations.                         |
| `BreadcrumbItem`      | `li`                   | Contains a link, current page, or menu trigger.    |
| `BreadcrumbLink`      | `a`                    | Accepts `href` and a `render` element or callback. |
| `BreadcrumbPage`      | `span`                 | Sets `aria-current="page"`.                        |
| `BreadcrumbSeparator` | `li`                   | Children replace the chevron.                      |
| `BreadcrumbEllipsis`  | `span`                 | Children replace the dots.                         |

All parts accept children, `className`, `style`, and forwarded refs. BreadcrumbLink's ref follows its rendered element; other refs target the listed native elements.

All seven parts and their prop types are exported from both `@ajnacloud/ui` and `@ajnacloud/ui/breadcrumb`.

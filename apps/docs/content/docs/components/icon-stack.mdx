## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { IconStack } from "@ajnacloud/ui";
```

### Granular

```tsx
import { IconStack } from "@ajnacloud/ui/icon-stack";
```

### Basic usage

```tsx
import { Inbox } from "lucide-react";

<IconStack aria-hidden="true">
  <Inbox className="size-4" />
</IconStack>;
```

IconStack draws a layered isometric surface and centers its children on top. Use it as decorative media for empty states, feature callouts, and compact list rows. Use [Empty](/docs/components/empty) when the message and actions need a full layout.

## Accessibility

IconStack is decorative. Add `aria-hidden="true"` and keep the meaning in surrounding text. The content layer ignores pointer events, so do not place buttons or links inside it.

## API reference

| Prop        | Type              | Default | Description                                        |
| ----------- | ----------------- | ------- | -------------------------------------------------- |
| `className` | `string`          | -       | Sets the outer size, text color, and layout.       |
| `children`  | `React.ReactNode` | -       | Decorative content centered on the top layer.      |
| `style`     | `CSSProperties`   | -       | Native styles; override the content position vars. |

IconStack renders a `div`, forwards a `HTMLDivElement` ref, and accepts native div props. Its content is positioned with `--ajna-icon-stack-content-x` and `--ajna-icon-stack-content-y`, which default to `71%` and `58%`.

`IconStack` and `IconStackProps` are exported from both `@ajnacloud/ui` and `@ajnacloud/ui/icon-stack`.

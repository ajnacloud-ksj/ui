## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { Spinner } from "@ajnacloud/ui";
```

### Granular

```tsx
import { Spinner } from "@ajnacloud/ui/spinner";
```

### Basic usage

```tsx
<Spinner aria-label="Loading projects" />
```

## Accessibility

Spinner defaults to `role="status"` and the name “Loading”. Supply `aria-label` for a specific or translated name, or `aria-labelledby` to reference existing text. `aria-hidden="true"` removes its default role and name. Reduced motion stops both animations, leaving a static arc.

## API reference

| Prop              | Type                               | Default     | Description                                 |
| ----------------- | ---------------------------------- | ----------- | ------------------------------------------- |
| `size`            | `"sm" \| "base" \| "lg" \| number` | `"base"`    | Both dimensions; numeric values are pixels. |
| `role`            | Native ARIA role                   | `"status"`  | Omitted when decorative.                    |
| `aria-label`      | `string`                           | `"Loading"` | Omitted when externally labelled or hidden. |
| `aria-labelledby` | `string`                           | —           | ID of the loading description.              |
| `aria-hidden`     | Native ARIA value                  | —           | Makes the spinner decorative.               |

Accepts `className`, `style`, native SVG props except `children`, `width`, and `height`, and an `SVGSVGElement` ref. Invalid runtime sizes fall back to `base`.

`Spinner`, `SpinnerProps`, and `SpinnerSize` are exported from both `@ajnacloud/ui` and `@ajnacloud/ui/spinner`.

## Usage

Complete [Installation](/docs/installation) once.

### Barrel

```tsx
import { Separator } from "@ajnacloud/ui";
```

### Granular

```tsx
import { Separator } from "@ajnacloud/ui/separator";
```

### Basic usage

```tsx
<Separator />
```

The default is a horizontal, 1px-high divider that fills its container's width.

### Decorative divider

Use presentation semantics when the line does not represent a meaningful content boundary.

```tsx
import { Separator } from "@ajnacloud/ui";

export function DecorativeDivider() {
  return <Separator role="presentation" aria-hidden="true" />;
}
```

## API reference

| Prop          | Type                             | Default        | Description                               |
| ------------- | -------------------------------- | -------------- | ----------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"`     | `"horizontal"` | Divider direction and `aria-orientation`. |
| `render`      | React element or render callback | —              | Replaces the default `div`.               |
| `className`   | String or state callback         | —              | Additional styles.                        |
| `ref`         | `Ref<HTMLDivElement>`            | —              | Ref to the underlying element.            |

Renders with `role="separator"` by default. Accepts native element and ARIA props; there is no `decorative` prop.

`SeparatorProps` and `SeparatorOrientation` are exported from both `@ajnacloud/ui` and `@ajnacloud/ui/separator`.
